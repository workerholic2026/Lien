이 자료는 뭔가요?

깃허브에 공개된 무료 자료 「앱스토어 규정 점검 모음(mjmirza/app-store-compliance)」을 쉽게 정리했어요. 애플 앱스토어·구글 플레이에서 실제로 반려된 이유 125가지를 모아 두고, 내 앱을 하나씩 대 보는 도구예요. 다만 만든 사람도 「승인을 보장하지 않는다」고 적어 뒀어요. 참고용으로 쓰세요.

1
설치 두 줄 (클로드 코드 기준)터미널(윈도우는 Git Bash)에 한 줄씩 붙여 넣어요. git clone https://github.com/mjmirza/app-store-compliance ~/repositories/app-store-compliance bash ~/repositories/app-store-compliance/scripts/install.sh --tool all → 다 되면 클로드 코드를 껐다 켜요. 그다음부터 앱을 심사에 올리려고 할 때마다 먼저 점검하고, 심각한 문제가 남아 있으면 올리기를 멈추고 고칠 곳을 알려 줘요. (git 과 bash 가 있어야 해요. 클로드 코드 말고 다른 도구는 python3 도 필요해요)
2
설치 없이 한 번만 점검하고 싶다면클로드 코드·커서 같은 코딩 AI를 내 앱 폴더에서 열고 아래를 통째로 보내요. 「https://github.com/mjmirza/app-store-compliance 의 docs 폴더와 data/rejection-patterns.json 을 읽고, 내 앱을 애플 앱스토어·구글 플레이 반려 사유 전부에 대 보고 점검해 줘. 결과는 심각한 순서(치명·높음·보통)로 표로, 항목마다 걸리는 규정과 고치는 법을 적어 줘. 마지막에 지금 심사에 넣어도 되는지 결론을 말해 줘. 시험용 계정, 개인정보 신고 내용, 앱 안 결제, 권한 요청, 계정 삭제는 꼭 봐 줘. 읽기만 하고 내 파일은 고치지 마.」
코딩을 안 한다면

저장소의 점검표(docs/PRE-SUBMISSION-CHECKLIST.md)를 열고 맨 앞 두 가지만 먼저 확인해요. 만든 사람 말로 5분이면 돼요.

시험용 계정 점검표 — 요즘 가장 많이 걸리는 첫째 이유

심사하는 사람은 내가 준 시험용 계정으로 로그인해서 앱을 실제로 써 봐요. 애플 심사 기준 2.1에도 「로그인이 필요한 앱이라면 시연 계정 정보를 넣고 백엔드 서비스가 가동 중인지 확인하라」고 적혀 있어요. □ 심사 정보 메모 칸에 시험용 아이디·비밀번호를 적었다 □ 그 계정으로 지금 실제로 로그인된다 (직접 해 보기) □ 문자·메일 인증(2단계 인증)이 걸려 있지 않다 □ 심사 중에 계정이 막히지 않게, 최소 2주는 살려 둔다 □ 로그인 뒤 핵심 기능이 오류 없이 돈다 = 앱 뒤에서 도는 서버가 켜져 있다 □ 핵심 기능까지 가는 순서를 1, 2, 3 번호로 적어 줬다 □ 결제가 있으면 결제·구매 복원 화면이, 회원이 있으면 계정 삭제 화면이 보이게 했다 원본 저장소의 심사 메모 틀에는 이것도 넣으라고 해요: 앱이 하는 일 한두 줄, 화면 녹화 영상 주소, 앱이 쓰는 바깥 서비스(로그인·결제·AI 등)와 쓰는 이유.

둘째 이유 — 개인정보 신고 내용

심사 때 신고한 개인정보 항목과 앱이 실제로 모으는 정보가 똑같아야 해요. 앱 안에 넣은 다른 회사 기능(로그인·광고·분석 도구 등)이 모으는 정보까지 포함이에요. 다르면 말로 설명하기보다 신고 내용을 고치거나 그 기능을 빼는 게 먼저예요.

3
반려됐을 때 — 애플 답장 순서1. 애플이 적어 준 규정 번호부터 정확히 읽어요 2. 오해라면 앱스토어 커넥트의 답장 창에 정확한 설명 + 화면 사진이나 녹화 + 시험용 계정으로 들어가는 길을 적어 보내요 3. 진짜 문제라면 고친 다음, 무엇을 어디서 바꿨는지 정확히 적어요 4. 심사가 틀렸다고 확신하면 「앱 심사 위원회」에 이의를 낼 수 있어요. 증거를 갖고, 꼭 필요할 때만 5. 규정의 취지를 두고 다투지 말고, 지적받은 규정에만 딱 맞춰 답해요
4
반려됐을 때 — 구글 플레이 이의 제기 순서1. 구글이 보낸 메일 속 이의 제기 링크로 들어가요 (어떤 정책인지 적혀 있어요) 2. 앱이 무엇을 하는지, 왜 정책에 맞는지, 무엇을 고쳤는지 정확히 적어요 3. 신고 내용이 달라서 걸렸다면 다투지 말고 신고 내용을 고치거나 그 기능·권한을 빼요 4. 반려된 같은 앱을 동시에 또 올리지 않아요 5. 계정 전체가 막혔다면 이의 제기가 유일한 길이에요. 빠짐없이, 정직하게 써요 만든 사람의 한 줄 요약: 지적받은 규정에 답하고, 증거를 보여 주고, 필요하면 앱을 고치고, 한 번에 다 담아 답장하기.
