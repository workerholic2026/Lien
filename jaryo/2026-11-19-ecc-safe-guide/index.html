해커톤 1위 개발자의 클로드 코드 세팅, 안전하게 받는 법

2026-11-19
이게 뭔가요?

앤트로픽·포럼벤처스 해커톤(짧은 기간에 모여 결과물을 만드는 개발 대회)에서 1위를 한 개발자로 여러 보도가 소개하는 아판 무스타파가, 평소 쓰던 클로드 코드 설정을 한 묶음으로 공개 저장소(github.com/affaan-m/ECC)에 올렸어요. 이름은 「에브리띵 클로드 코드」, 사용 허락은 누구나 무료(MIT)예요.

⚠️ 클로드 공식 자료는 아니에요

앤트로픽이 만든 제품이 아니에요. 저장소에도 공식 제품이라는 말이 없어요. 개인 개발자가 만든 설정 묶음이라서, 받기 전에 아래 확인 3가지를 먼저 보세요.

안에 무엇이 들어 있나요? (저장소 소개표 기준)

① 일하는 AI 72개 — 클로드가 역할을 나눠 맡기는 도우미예요. 저장소 목록에서 확인한 예: 계획 세우기(planner) · 코드 검토(code-reviewer) · 오류 고치기(build-error-resolver) · 보안 점검(security-reviewer) · 시험부터 쓰게 하기(tdd-guide) · 필요 없는 코드 정리(refactor-cleaner) · 문서 갱신(doc-updater) ② 업무 설명서(스킬) 327개 — 「이런 일은 이런 순서와 규칙으로 하라」고 적어 둔 설명서예요. 클로드가 일을 시작할 때 읽고 따라 해요. ③ 명령어 98개 — 클로드 코드 창에서 한 줄로 일을 시키는 말이에요. 저장소 목록에서 확인한 예: /plan(계획) · /code-review(코드 검토) · /build-fix(오류 고치기)

1
공식 주소 확인저장소가 밝힌 공식 곳은 깃허브 github.com/affaan-m/ECC, 설치 패키지 ecc-universal·ecc-agentshield, 플러그인 이름 ecc@ecc, 사이트 ecc.tools 예요. 그 밖의 곳에서 다시 올린 사본은 받지 마세요.
⚠️ 복사본은 받지 마세요

저장소가 직접 「관리도 검토도 안 되는 사본에는 악성 코드가 있을 수 있다」고 경고해요. 블로그·메신저로 돌아다니는 압축 파일이나 다른 사이트 복사본은 피하세요.

2
설치 방법은 한 가지만저장소는 설치 방법을 겹쳐 쓰지 말라고 안내해요. 클로드 코드 창에 아래 두 줄을 차례로 입력하는 것이 저장소가 알려 주는 방법 중 하나예요.
설치 ① 도구 목록 추가
/plugin marketplace add https://github.com/affaan-m/ECC
설치 ② 설치
/plugin install ecc@ecc
3
받기 전에 클로드에게 물어보기클로드 대화창에 아래 말을 먼저 붙여 넣어 보세요. 무엇이 설치되는지, 조심할 점이 무엇인지 쉬운 말로 알려 줘요.
복사해서 물어보기
이 저장소가 무엇을 설치하는지, 조심할 점이 뭔지 쉬운 말로 알려 줘: github.com/affaan-m/ECC
코딩이 낯설다면

설치에는 클로드 코드 창에서 명령을 입력해야 해요. 낯설다면 지금은 구경만 하고, 개발 담당자에게 먼저 맡겨 보세요. 설치하면 설정이 바뀌므로 업무용 컴퓨터는 회사 규칙을 먼저 확인하세요.

확인한 것과 못 한 것

확인한 것: 72·327·98개는 저장소 소개표 기준이고(저장소 안 다른 곳에는 다른 숫자도 보여요), 하는 일의 예는 저장소의 실제 파일 이름이에요. 해커톤 1위는 여러 매체 보도 기준이고 앤트로픽이 직접 밝힌 글은 확인하지 못했어요.
