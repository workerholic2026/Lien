폰 슬랙으로 AI 직원 부리는 법 — 실제 설정 순서

2026-11-22
전체 구조 먼저

① 폰 슬랙에 메시지를 쓴다 → ② 슬랙 앱(봇)이 그 메시지를 받는다 → ③ 컴퓨터에서 도는 「연결 프로그램」이 받아서 클로드 코드에 넘긴다 → ④ 클로드 코드가 일하고 → ⑤ 같은 길로 슬랙에 답을 올린다. 그래서 필요한 건 슬랙 앱 1개, 열쇠 2개, 연결 프로그램 1개, 늘 켜진 컴퓨터 1대예요. 처음 설정은 1~2시간 걸려요.

⚠️ 미리 알아 둘 것

· 클로드 코드가 메시지를 받아 바로 일하는 「채널」 기능은 아직 시험 단계 기능이에요. 켤 때 「개발용 채널」 확인 창이 뜨고, 나중에 방식이 바뀔 수 있어요. · 회사 슬랙이 아니라 내가 주인인 새 작업 공간에서 하세요. 회사 슬랙은 관리자 허락 없이 앱을 못 깔아요.

1
준비물 설치· 클로드 프로 이상 요금제 · 늘 켜 둘 컴퓨터(윈도우·맥 모두 돼요) · Node.js(프로그램을 돌리는 바탕 프로그램): nodejs.org 에서 LTS 판 설치 · 클로드 코드: 명령 창에 아래 줄을 넣고, 설치되면 claude 를 입력해 클로드 계정으로 로그인해요
클로드 코드 설치
npm install -g @anthropic-ai/claude-code
2
슬랙 작업 공간과 채널 만들기slack.com 에서 새 작업 공간을 무료로 만들어요. 그다음 일 종류별로 채널을 만들어요. 예: #영상 #조사 #문서. 폰에 슬랙 앱을 깔고 같은 계정으로 로그인해 두세요.
3
슬랙 앱(봇) 만들기api.slack.com/apps → 「Create New App」 → 「From a manifest(설정 글로 만들기)」 → 작업 공간 고르기 → 아래 설정 글을 통째로 붙여 넣기 → Create. 이 설정 글에 봇이 읽고 쓸 권한과 「소켓 모드(내 컴퓨터가 슬랙에 직접 붙는 방식, 서버·주소 필요 없음)」가 다 들어 있어요.
붙여 넣을 설정 글
{"display_information":{"name":"AI 직원"},"features":{"bot_user":{"display_name":"ai-staff","always_online":true},"app_home":{"messages_tab_enabled":true,"messages_tab_read_only_enabled":false}},"oauth_config":{"scopes":{"bot":["app_mentions:read","channels:history","channels:read","channels:join","im:history","im:read","im:write","chat:write","chat:write.customize","files:read","files:write","reactions:write","users:read"]}},"settings":{"event_subscriptions":{"bot_events":["app_mention","message.channels","message.im"]},"socket_mode_enabled":true}}
4
열쇠 2개 받기열쇠 ①: 왼쪽 메뉴 「Install App」 → 「Install to Workspace」 → 허용. 나오는 「Bot User OAuth Token」(xoxb- 로 시작)을 복사해요. 열쇠 ②: 「Basic Information」 → 아래쪽 「App-Level Tokens」 → 「Generate Token and Scopes」 → 이름 아무거나, 권한 connections:write 추가 → Generate. 나오는 값(xapp- 로 시작)을 복사해요. 두 열쇠는 비밀번호와 같아요. 남에게 보여 주거나 대화창·인터넷에 올리지 마세요.
5
내 슬랙 아이디 확인슬랙에서 내 프로필 → 「⋮」 → 「멤버 ID 복사」(U 로 시작). 연결 프로그램이 이 아이디가 보낸 말만 받게 해야, 다른 사람이 내 컴퓨터에 일을 시키지 못해요.
6
연결 프로그램 만들기컴퓨터에 새 폴더(예: 문서\ai-staff)를 만들고, 그 폴더 안에 「열쇠.env」 파일을 만들어 두 열쇠를 한 줄씩 적어요. 그다음 그 폴더에서 클로드 코드를 켜고 아래 지시를 그대로 붙여 넣어요. 연결 프로그램은 슬랙 메시지를 받아 클로드 코드에 「채널 알림」으로 넘기고, 클로드의 답을 슬랙에 올리는 작은 프로그램이에요. 다 만들면 클로드가 시험까지 해 줘요.
클로드 코드에 붙여 넣을 지시
이 폴더에 슬랙 연결 프로그램을 만들어 줘. 조건: ① 클로드 코드 채널(claude/channel) 기능을 쓰는 MCP 서버, 노드로 만든다 ② 슬랙 소켓 모드로 붙는다. 열쇠는 이 폴더 열쇠.env 의 xoxb·xapp 값을 읽고 화면에 찍지 않는다 ③ 내 멤버 ID(여기에 붙여 넣기)가 보낸 메시지만 클로드에게 넘긴다 ④ 받은 메시지에는 👀 반응을 단다 ⑤ 답하기(reply), 파일 올리기, 첨부 내려받기 도구를 만든다 ⑥ 이 프로그램을 쓰는 설정 파일(mcp 설정 json)과 켜는 명령까지 만들고, 내가 할 일은 쉬운 말로 단계별로 알려 줘.
7
켜기클로드가 만들어 준 켜는 명령을 실행해요. 모양은 아래와 비슷해요. 켤 때 「개발용 채널」 확인 창이 뜨면 「로컬 개발용으로 쓴다」를 골라요. 그다음 슬랙 채널에서 /invite @ai-staff 로 봇을 부르고, 「안녕」을 보내 보세요. 👀 반응이 붙고 답이 오면 성공이에요.
켜는 명령 모양
claude --mcp-config 설정파일.json --dangerously-load-development-channels server:slack
8
늘 켜 두기· 켜는 명령을 .cmd(윈도우) 파일로 저장하고, 그 바로가기를 시작프로그램 폴더(윈도우키+R → shell:startup)에 넣으면 컴퓨터가 켜질 때 저절로 켜져요 · 설정 → 전원 → 「절전 모드: 안 함」으로 바꿔요. 잠들면 답이 안 와요 · 그 창을 닫으면 슬랙도 멈춰요. 최소화만 하세요
9
직원 나누고 규칙 주기작업 폴더에 CLAUDE.md 파일을 만들고 「#영상 채널 말은 영상 담당으로 답한다, 말투는 이렇게, 결과는 이 폴더에 저장」처럼 채널별 담당과 규칙을 적어요. 클로드 코드는 켜질 때마다 이 파일을 읽어요. 지적한 내용은 그때그때 「규칙에 넣어」라고 하면 같은 실수가 줄어요.
10
기억 잇기대화가 길어지거나 다시 켜지면 클로드는 앞 일을 잊어요. CLAUDE.md 에 「일이 끝나면 작업일지.md 맨 위에 한 일·정한 것·다음 할 일을 적는다, 켜지면 먼저 읽는다」를 적어 두세요. 창이 꺼져 있던 동안 온 메시지는 다시 켜도 저절로 오지 않으니, 켜질 때 지난 메시지를 확인하게 하는 것도 좋아요.
첫 지시 예시

· 「이번 주 AI 소식 3개 찾아서 출처 붙여 정리해」 · 「이 회의 메모로 보고서 써서 파일로 줘」 · 「이 주제로 30초 영상 대본 써 줘」 · 「매일 아침 8시에 오늘 할 일 알려 줘」(정해진 시간 일은 윈도우 작업 스케줄러에 걸어 달라고 하세요)

⚠️ 막히는 곳

· 답이 없다 → 켜 둔 창이 닫혔거나 컴퓨터가 잠들었어요. 창부터 확인 · 「not_in_channel」 오류 → 그 채널에 봇을 /invite 하지 않았어요 · 「invalid_auth」 → 열쇠를 잘못 붙였어요. 앞뒤 빈칸 없이 다시 · 메시지는 오는데 일을 안 한다 → 켤 때 「개발용 채널」 확인에서 다른 걸 골랐어요. 다시 켜서 로컬 개발용 선택 · 확인 질문이 계속 떠서 멈춘다 → 클로드 코드는 위험한 일 전에 허락을 물어요. 밖에서는 못 누르니, 자주 하는 일은 「허락 목록」에 넣어 달라고 하세요 · 회사 컴퓨터라면 회사 보안 규칙을 먼저 확인하세요
