네이버 검색 API 키, 새로 받는 법과 주의할 점

2026-11-21
API 키가 뭐고, 뭘 할 수 있나요?

API 키는 프로그램이 네이버 검색을 쓸 수 있게 해 주는 아이디·비밀번호 한 쌍이에요. 이 키로 프로그램이 할 수 있는 일: ① 우리 업종 최신 뉴스 제목·링크 모으기 ② 블로그·카페 후기 흐름 보기 ③ 지식iN 질문 모으기 ④ 검색어 트렌드로 언제 많이 찾는지 보기 ⑤ 쇼핑 인사이트로 요즘 많이 찾는 말 보기. 쇼핑 최저가 검색은 7월 말에 끝나서 이제 안 돼요.

⚠️ 옛날 방법(개발자센터)은 따라 하지 마세요

예전엔 「네이버 개발자센터」에서 키를 받았어요. 올해 7월 말부터 개발자센터는 새 신청을 받지 않고, 받아 둔 키도 2027년 6월에 끝난다고 안내됐어요(보도·안내 메일 기준). 옛 키는 새 곳에서 쓸 수 없고 부르는 주소도 바뀌어서, 블로그 옛날 글대로 하면 오류가 나요.

새로 받는 곳: 네이버 클라우드 플랫폼 안의 「API 허브」

네이버 클라우드 플랫폼(ncloud.com)은 네이버의 회사용 서비스 모음이에요. 그 안에 있는 서비스 하나가 「NAVER API HUB(API 허브)」예요.

1
네이버 클라우드에 로그인ncloud.com 에 로그인해요. 가입할 때 결제 카드 등록을 요구할 수 있다는 후기가 있어요(공식 문서엔 적혀 있지 않아요).
2
API 허브 찾기메뉴 → All Services(전체 서비스) → Application Services → NAVER API HUB 로 들어가요.
3
이용 신청Subscription(구독) 화면에서 「이용 신청」을 누르고 약관에 동의해요.
4
Application 등록하고 쓸 검색 고르기Application 메뉴 → 「Application 등록」 → 뉴스·블로그처럼 쓸 검색을 고르고 「다음」. 이름은 영어·숫자·하이픈(-)만, 20자까지예요.
5
「인증 정보」에서 키 두 개 확인등록이 끝나면 목록의 「인증 정보」 단추를 눌러요. Client ID(아이디 키)와 Client Secret(비밀번호 키) 두 개가 나와요. 누르면 복사돼요.
무료 한도

검색은 하루 25,000번(한 달 775,000번)까지, 검색어 트렌드·쇼핑 인사이트는 한 달 50,000번까지예요. 지금은 한시적 무료이고, 유료로 바뀌면 미리 알려 준다고 공식 문서에 있어요. 한도에 닿으면 자동으로 멈춰요.

⚠️ 키는 절대 남에게 보이지 마세요

두 키를 채팅방·메신저·캡처 화면에 그대로 올리지 마세요. 새어 나간 것 같으면 「인증 정보」 창에서 Client Secret 을 바로 다시 받으세요.

⚠️ 검색 결과를 AI에 넣는 건 조심

9월에 약관이 바뀌어 검색 결과를 AI에 넣거나 저장·가공해서 내 것처럼 보여 주는 것이 막혔다는 보도가 있어요. 공식 원문은 아직 확인 못 했으니, 결과는 내가 직접 보는 용도로 쓰세요.
