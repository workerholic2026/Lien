연결 안 되던 내 컴퓨터 프로그램, 이제 클로드가 직접 다룹니다 🔌 노션·지메일처럼 연결 도구(커넥터)가 있는 서비스는 클로드에 바로 붙어요. 그런데 3D 프로그램, 방송·녹화 프로그램, 사진 편집 프로그램처럼 내 컴퓨터에 깔린 프로그램은 대부분 커넥터가 없어서 클로드가 손을 댈 수 없었어요. 이 빈자리를 채우는 무료 공개 도구가 「CLI-Anything」이에요. 📌 CLI-Anything이 뭔가요? 홍콩대학교 데이터 연구실(HKUDS)이 깃허브에 무료로 공개한 도구예요. 프로그램을 버튼 대신 글자 명령으로 움직이게 해 주는 작은 연결 도구를, 클로드가 직접 만들게 해 줘요. 연결 도구가 생기면 명령은 클로드가 대신 입력하니까 우리는 말로만 시키면 돼요. 깃허브에서 별(관심 표시)을 6만 개 넘게 받은 인기 도구예요. 📌 두 가지 길이 있어요 첫째, 이미 만들어진 연결 도구 받기. 「CLI-Hub」라는 모음에 3D(블렌더)·사진 편집(김프)·방송 녹화(OBS)·녹음 편집(오다시티)·영상 편집·문서 프로그램용 연결 도구가 100개 넘게 올라와 있어요. 목록에 있으면 받아서 바로 써요. 둘째, 없으면 새로 만들기. 프로그램의 깃허브 주소만 알려 주면 클로드가 코드 분석부터 설계, 만들기, 시험, 설치까지 7단계를 혼자 진행해요. 스스로 시험해 보고 고친 뒤에 설치하는 구조예요. 📌 연결하면 이런 일이 돼요 · 3D 프로그램(블렌더) 화면을 한 번도 열지 않고 「원숭이 모형 넣고 초록색으로 칠해서 그림으로 뽑아줘」 · 사진 화질 높이는 프로그램으로 「이 사진 4배로 키워줘」 · 도표 프로그램으로 「이 순서를 그림으로 그려줘」 프로그램 창을 오가며 버튼을 누르던 일을 대화 한 줄로 바꾸는 거예요. 📌 미리 알아 두세요 · 클로드 앱의 코드(Code) 탭에서 쓰는 도구라 유료 요금제가 필요해요 · 새로 만들 때는 시간이 꽤 걸리고(한 사례는 약 23분) 클로드 사용량도 많이 써요. 목록에 있으면 받아 쓰는 게 훨씬 빨라요 · 연결 도구는 내 컴퓨터에서 명령을 직접 실행해요. 믿을 수 있는 프로그램만 연결하고, 중요한 파일은 복사본을 먼저 만들어 두세요 · 코드가 공개된 프로그램일수록 잘 만들어져요 💬 준비물, 설치 순서, 막혔을 때 해결법(윈도우 오류 포함)을 정리한 자료가 있어요. 댓글에 「연결」이라고 남겨 주시면 DM으로 보내 드릴게요. 출처: CLI-Anything 공식 깃허브(HKUDS/CLI-Anything) · 누끼토끼 연결 안내(2026-11-19) #클로드 #클로드코드 #AI자동화 #CLIAnything #AI소식
